# منصة مناسبة | بطاقات ودعوات زفاف إلكترونية تفاعلية فاخرة
### High-End Interactive Arabic Digital Wedding Invitations Platform

منصة ويب متكاملة وعالية الأداء مخصصة لإنشاء وإدارة ومشاركة بطاقات الدعوة الرقمية الفاخرة للأفراح والمناسبات الملكية، مبنية بأحدث معايير الويب ومتوافقة تماماً مع الخطوط العربية الراقية واتجاه النصوص من اليمين لليسار (RTL).

---

## 🌟 مميزات المنصة (Key Features)

### 1. خمسة قوالب فاخرة ومتميزة (5 Distinct Invitation Themes):
- **قالب ١: "باب الفرح / الأقواس الكلاسيكية" (`/d/demo-bab`)**:
  - مستوحى من جمالية وعراقة مرجع `halaheel.com/d/demo-bab` مع **حذف كامل لفيديو الباب ونقرات الطرق الثلاث**؛ لتبدأ الدعوة مباشرة بواجهة بصرية ملكية آسرة (Hero Section) بانتقالات انسيابية ناعمة.
  - إطار أقواس إسلامية وأندلسية، زخارف مشربية مائية، وتدرجات ذهبية وزمردية ملكية.
- **قالب ٢: "المودرن البسيط" (`/d/modern-minimalist`)**:
  - خلفية عاجية هادئة (Alabaster Off-white)، إطارات ذهبية دقيقة، خطوط تحريرية ناعمة، وزخارف نباتية مبسطة.
- **قالب ٣: "الورود الملكية" (`/d/royal-floral`)**:
  - ألوان الباستيل الرومانسية (Blush Pink & Sage Green)، إكليل زهور مائي، مع محاكاة بتلات ورد متطايرة ومتحركة.
- **قالب ٤: "ليلة العمر / الفخامة الليلية" (`/d/midnight-stars`)**:
  - سواد ليلي عميق، بريق النجوم المتلألئة، تفاصيل الذهب والشمبانيا المعدنية، وطابع فلكي ساحر.
- **قالب ٥: "التراث الأصيل" (`/d/heritage-andalus`)**:
  - ألوان التيراكوتا ورمال الصحراء الدافئة، خط الرقعة الأصيل، ونقوش المشربية التقليدية.

---

### 2. نظام تأكيد الحضور الذكي بلمسة واحدة (Single-Tap Anti-Spam RSVP):
- زر تأكيد الحضور المباشر بنقرة واحدة ("سأحضر").
- حماية صارمة تمنع التكرار والنقر العشوائي (One-Tap Per Device Policy) عبر دمج بصمة العميل البرمجية (`Client Device Fingerprint`) مع تخزين `localStorage`.
- تأثير احتفالي مبهج (Celebration Confetti) عند التأكيد، مع تحول الزر إلى الحالة المغلقة (`تم تأكيد حضورك بنجاح ✓`).
- بدون حقول إدخال مزعجة أو تعليقات مشتتة.

---

### 3. تكامل التقويم والملاحة الجغرافية:
- **تقويم Google**: رابط مباشر يفتح تطبيق أو موقع Google Calendar مع تعبئة العنوان والوصف والتاريخ تلقائياً.
- **تقويم Apple (.ics)**: تنزيل فوري لملف iCalendar معتمد قياسياً (RFC 5545) لإضافته لتقويم أجهزة iPhone و Mac بلمسة واحدة.
- **خرائط Google**: بطاقة قاعة الحفل مع زر ملاحة مباشر لخرائط Google.
- **عداد تنازلي مباشر**: أيام، ساعات، دقائق، ثوانٍ مع أرقام وتواريخ عربية وهجرية منسقة.
- **تنبيه الأطفال**: بطاقة راقية لتنويه "جنة الأطفال منازلهم".

---

### 4. لوحة الإدارة الخفية (`/admin`):
- **مسار خفي وغير معلن**: لا توجد أي روابط أو أزرار تؤدي للوحة الإدارة في واجهات الدعوة أو الهيدر/الفوتر.
- **بوابة حماية بكلمة مرور**: محمي بكلمة مرور (الافتراضية: `admin123`).
- **إحصائيات فورية**: إجمالي الدعوات، وعدد الحضور المؤكدين الفعلي (RSVP Counter).
- **إنشاء وتعديل الدعوات**:
  - اختيار القالب (من 1 إلى 5).
  - أسماء العروسين وأولياء الأمور ونصوص الترحيب.
  - تخصيص ديناميكي للآيات القرآنية والأبيات الشعرية بنقرة واحدة.
  - مفاتيح تفعيل/تعطيل الأقسام (Toggles): العداد، التقويم، الموقع، تأكيد الحضور، تنبيه الأطفال، والزي الرسمي.
  - إدارة فقرات برنامج الحفل (Timeline).
  - إمكانية إعادة ضبط وتصفير عداد الحضور لأي دعوة.
  - نسخ الروابط الفريدة بنقرة واحدة ومشاركتها عبر واتساب.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19, TypeScript)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) + Canvas Confetti
- **Typography**: Google Fonts (Amiri, Cairo, Tajawal, Aref Ruqaa)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Service Layer**: نظيفة ومفصولة (`src/lib/invitation-service.ts`) جاهزة للربط الفوري مع Supabase أو SQLite أو PostgreSQL.

## 🚀 التشغيل المحلي (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```

افتح المتصفح على:
- الواجهة الرئيسية للقوالب: [http://localhost:3000](http://localhost:3000)
- قالب باب الفرح (نموذج 1): [http://localhost:3000/d/demo-bab](http://localhost:3000/d/demo-bab)
- لوحة الإدارة الخفية: [http://localhost:3000/admin](http://localhost:3000/admin) (كلمة المرور: `admin123`)

## ☁️ النشر على Vercel عبر GitHub (Vercel Deployment)

1. أنشئ مستودعاً جديداً على GitHub:
```bash
git init
git add .
git commit -m "Initial commit: Luxury Arabic wedding invitation platform"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```
2. توجه إلى [Vercel](https://vercel.com) وانقر على **"Add New Project"**.
3. استورد المستودع من GitHub واضغط **"Deploy"**.
4. سيتكفل Vercel ببناء المشروع تلقائياً ونشره في ثوانٍ معدودة دون الحاجة لأي إعدادات إضافية.
